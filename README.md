# Customer Churn Prediction

## Problem
Identify customers at risk of churn and rank risk scores for retention targeting.

## Data
The repository includes the project notebook and spreadsheet exports. Review the files for anonymization and remove any real personal or customer identifiers before public sharing. Do not use identifiable customer data for a public demo.

## Approach
Built an XGBoost churn classifier and produced ranked risk scores.

## Result
The model achieved approximately **95% accuracy** and **0.82 F1 for the churn class**.

## How to Run
1. Clone this repository.
2. Review the notebook's expected input paths and use only anonymized data.
3. Install Python, Jupyter, pandas, NumPy, scikit-learn, and XGBoost.
4. Open and run the Customer Churn Prediction notebook.

## Tech Stack
Python, pandas, NumPy, scikit-learn, XGBoost, Jupyter Notebook
